It creates no WebSocket, fetch, provider call, storage write or game mutation; its response CSP denies connections and permits only same-origin framing, with matching `X-Frame-Options: SAMEORIGIN`. Only the designated static `/overlay` parent permits `frame-src 'self'`; that parent still denies scripts, connections, forms and its own framing. Other demo routes retain their default-deny frame loading, and live-overlay/control/auth framing policies are unchanged. A same-origin embedding parent may send exactly `{type:'raid-relic-preview-arrival',role:'source'|'host'}` to switch fictional roles. The normal live overlay has no such message listener. This is neither a real overlay broadcast nor green readiness evidence.
